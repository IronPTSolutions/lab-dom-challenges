Que es el DOM? ▼

El DOM (Document Object Model) es una representacion en forma de arbol de la estructura de un documento HTML. Permite a JavaScript acceder y manipular los elementos de la pagina.

Que es un event listener? ▼

Un event listener es una funcion que se ejecuta cuando ocurre un evento especifico en un elemento del DOM, como un click, un hover o una pulsacion de tecla.

Que diferencia hay entre querySelector y getElementById? ▼

getElementById busca un elemento por su atributo id, mientras que querySelector acepta cualquier selector CSS valido y devuelve el primer elemento que coincida.

Que es la delegacion de eventos? ▼

La delegacion de eventos es una tecnica donde se añade un solo event listener a un elemento padre en lugar de a cada hijo individual. Aprovecha el bubbling de eventos para manejar clicks en elementos hijos.
